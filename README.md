## SOlANA contracts for the SOLANA x Swinburne Hackathon

**Overview**

This project demonstrates how to create and manage NFT Collections and NFT assets on the Solana blockchain using the Metaplex framework.

The application allows a connected wallet to:

Create a new NFT Collection

Mint NFTs under a Collection

This project is designed as a frontend dApp interacting with Solana smart contracts using the Metaplex SDK.
